# Pi Lab Security Homelab

A hands-on, documented Linux security homelab built on a Raspberry Pi 4 
running Ubuntu Server 24.04.4 LTS.

## Purpose
Building practical skills and portfolio evidence toward a career as an 
AI Security Engineer. Every section is built, validated, and documented 
in real time.

## Hardware
- Raspberry Pi 4 Model B — 8GB RAM / 64GB microSD
- Ubuntu Server 24.04.4 LTS (aarch64)
- MacBook Pro 2019 — workstation and management
